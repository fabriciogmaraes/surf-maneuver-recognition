# data/

Local data, not versioned except `splits.csv`.

- `raw/data-split/`: original dataset (Surf Maneuver Recognition, Hugging Face: https://huggingface.co/datasets/2nzi/surf-maneuvers)
- `processed/`: cached features and surfer boxes (rebuilt by notebooks 02, 03 and 08)
- `external/`: unseen test videos (Pexels) and annotated outputs
- `splits.csv`: session-aware split (notebook 02)
